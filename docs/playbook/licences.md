# Licences and release

Load when: adding a source, a credit, or preparing a level release. Source: [archive/level-playbook-full.md](archive/level-playbook-full.md) §9.

- Show each Tatoeba sentence's author. Settings lists them all; one generic credit line does not meet CC BY.
- Credit EDRDG whenever `jmdict` appears in `sources`. Credit Tanos with its author and a licence link. Precache the licence files so Settings links work offline.
- State the content licence: code MIT, own content CC BY 4.0.
- Japanese UI strings stay hidden (`UI_JA_READY`) until a native speaker reviews them.
- The README is part of the release. Update it before the level ships.
- Credit every source a level adds to `sources` (Wiktionary for kanji). A new source in the grammar `sources` (Bunpro, japanesetest4you, Genki index, Tae Kim) is a link for a level claim, not copied text. Keep it that way.
