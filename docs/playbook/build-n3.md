# Building N3: step by step

Load when: building N3. Source: [archive/level-playbook-full.md](archive/level-playbook-full.md) §11. Each step lists the topic files to load, so read only those.

Run each step on its own branch in a worktree; commit, run the suite, land by rebase + fast-forward. Add every new `data/n3/*.js` to `index.html` and `tests.html` (after the N4 block), rebuild `sw.js` in the branch's last commit. Keep `STATE.md` and the expected-red list current.
